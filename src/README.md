# Src

Runtime code for Klimkit lives under `src/klimkit/`.

Core operator surfaces:

- `src/klimkit/tools/`: machine daemons and host-side operational tooling
- `src/klimkit/apps/`: user-facing helpers and small app bundles
- `src/klimkit/tools/supervisor/`: single supervisor that handles live sync plus role-based runtimes

Additional local tools:

- `src/klimkit/analysis/`: maintained analysis helpers
