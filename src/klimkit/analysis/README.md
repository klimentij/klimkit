# Analysis

This folder holds exploratory but maintained analysis utilities for large imported corpora.

## Current tools

- `python3 -m klimkit.analysis.chatgpt_archive_eda`
  - title- and archive-level exploratory analysis for the staged ChatGPT export archive
- `python3 -m klimkit.analysis.chatgpt_export_eda`
  - zip-level EDA for split ChatGPT export bundles, oriented toward topic design and filtering

These scripts are for classification and planning, not for canonical wiki writes.
