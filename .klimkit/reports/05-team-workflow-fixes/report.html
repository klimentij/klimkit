Why This Fix Exists

The original PR got the direction right

Dominik's PR turned `.klimkit` into a shared project evidence layer with per-operator write boundaries. That matches the Klimkipedia team-Klimkit discussion: useful task notes, logs, memories, reflections, and proof reports should compound across a team instead of dying on a single VM.

The issue was not the idea. The issue was hardening the boundary so light team support does not make solo mode fragile or expose unintended files.

The implemented stance

Solo stays boring and default. A fresh config still renders `workflow = "solo"` and keeps the flat `.klimkit/memory.md`, `.klimkit/log.md`, `.klimkit/reflection.md`, `.klimkit/tasks/`, and `.klimkit/reports/` model. Team mode is activated only by explicit config or an intentional migration command.

After Klim clarified that this repository itself must remain solo, the committed proof evidence was flattened back into the solo `.klimkit/` layout and contributor operator-scoped `.klimkit` artifacts were removed from the public repo.

What Changed

AreaBeforeAfter
Migration names `human_name = "tasks"` could produce `.klimkit/tasks/tasks` and partially move files before crashing. Reserved top-level names such as `tasks`, `memory.md`, `log.md`, `reflection.md`, `reports`, `local`, `state`, `backups`, and `logs` are rejected before planning moves.
Migration preflight Some source/target overlaps were discovered only during `shutil.move`. The plan blocks reserved names, trailing-punctuation operator folders, malformed source artifact shapes, existing or partially migrated targets, source/target overlaps, and symlinked roots before any move, then writes `workflow = "team"` only after safe completion.
Dry-run commands The printed `Next` command dropped explicit `--config`, `--repo`, or quote-sensitive values. The command is produced with `shlex.join`, preserving explicit context, `KLIMKIT_CONFIG`, inferred project paths, and safe shell quoting.
Reports .klimkit/<dir>/reports looked like an operator report source, including .klimkit/tasks/reports. Only flat .klimkit/reports and valid .klimkit/<operator>/reports are accepted; reserved pseudo-owners, duplicate roots, symlinked .klimkit roots, symlinked operator roots, and symlink escapes are rejected or skipped.
Codex pack One migration-conflict sentence said to ask `Human`. The pack now uses `__HUMAN_NAME__`, and validation prevents reintroducing `ask Human`.
Repo evidence The PR branch carried operator-scoped committed evidence under `.klimkit/Klim/` and `.klimkit/Dominik/`. This repository is back to flat solo evidence: `.klimkit/tasks/`, `.klimkit/reports/`, `.klimkit/memory.md`, `.klimkit/log.md`, and `.klimkit/reflection.md`; `git ls-files .klimkit/Klim .klimkit/Dominik` returns no paths.
